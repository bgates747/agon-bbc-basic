# C003 — Scalar variables and mutable strings — DRAFT

This task defines the future variable and string runtime. The bootstrap only
prints literals; it does not implement mutable strings or numeric variables.
No implementation has begun under this ID.

## Identity, status and dependencies

1. Immutable ID: **C003**. Status: **planned; not started**.
2. Origin: the Author requires BBC BASIC variable conventions and string
   semantics, including compatibility with LOCAL restoration.
3. Dependencies: [C001](C001.md) for native emission and [C002](C002.md) for
   numeric values/conversion. Inputs include the string/heap investigation in
   [REFERENCE.md](../../compiler/REFERENCE.md).

## Scope

1. Specify suffix-based types, unsuffixed numeric variables, name identity,
   initialisation rules and binding slots using the reference interpreter.
2. Implement mutable length-aware strings, empty values, assignment, copying,
   allocation, growth and resource-limit errors. Define ownership across
   expression temporaries, aliases and later procedure/local boundaries.
3. Specify heap bounds, stack separation and allocation failure behavior.
   Interpreter globals and allocation assumptions must be replaced or
   deliberately initialised, not called through arbitrary interpreter addresses.

## Acceptance criteria

1. Differential tests establish variable naming/type and assignment semantics,
   including numeric conversion and enabled undefined-variable behavior.
2. String tests cover empty/maximum length, embedded zero bytes, repeated
   reassignment, growth, self-assignment and source/destination independence.
3. Churn and exhaustion tests show defined memory behavior and clear failure;
   no descriptor corruption or unbounded accidental interpreter-style leaks
   are silently accepted as the runtime policy.
4. The ownership/binding contract supports the save/restore requirements of
   [C004](C004.md) and is recorded in the specification before promotion.
