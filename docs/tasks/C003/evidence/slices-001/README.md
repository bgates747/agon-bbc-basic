# Slicing and comparison prototype qualification

rejections, deterministic repeat, independent links, raw string contents and
write guards, a direct slice/comparison ABI probe, and the complete baseline
assembly oracle. See summary.json for counts and host qualification durations.

original build paths. No hardware/human graphical or benchmark claim is made.
