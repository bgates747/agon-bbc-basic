## Acceptance criteria

1. The stable card root contains the unchanged native compiler, its BBC source,
   an existing documented text editor, applicable notices, a starter program,
   supported-language information and a hardware-readable `readme.txt`.
   Consumer payloads must work at arbitrary installation roots and contain no
   maintainer hostnames, mountpoints, repository or task-evidence paths.
2. Editing, saving ordinary text, compiling and running have exact MOS commands.
   The editor's moslet address differs from the compiler's program address and
   must be documented correctly. No interpreter or assembler is required.
3. Manual test subdirectories reuse previously qualified inputs/oracles and
   describe expected output/rejection, separate fresh output names, error/file
   effects and duration/progress limits. They must not autorun or claim a pass.
4. Validate the exact mounted destination, preserve existing unrelated/user
   contents, synchronize writes and leave the card mounted. Retain package
   identities and the actual deployment receipt, without redundant readbacks.
5. Record manual results only after the Author reports actual execution.
