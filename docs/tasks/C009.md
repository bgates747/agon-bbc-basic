# C009 — Possible anonymous labels

Record anonymous labels with nearest forward/backward references as a possible
language extension. This is a low-priority roadmap candidate, not a commitment
to implement it or adopt a particular spelling.

## Identity and status

1. Immutable ID: C009. Priority: low. Status: deferred candidate; unstarted.
2. Origin: the Author's2026-11-03 request to record the anonymous-label idea
   discussed by analogy with eZ80 assembler facilities, including ZDS II.
3. Authorization covers recording the possibility only. No compiler changes,
   prototype, emulator work, hardware reservation or deployment are selected.

## Consideration scope

1. Consider repeatable anonymous label declarations and references to the nearest
   preceding or following declaration, resolved during compilation.
2. Choose syntax explicitly. The illustrative `@@:`, `@B`, `@F` spellings are
   not approved: `@B` and `@F` already fit valid named-label identifiers and
   must not be reserved silently. Verify any claimed assembler precedent from
   its actual documentation before relying on it.
3. Define the search boundary and missing-target diagnostics. Consider PROC/FN
   label scopes separately from variable names and LOCAL semantics; GOSUB does
   not itself create a new label scope. Do not change numbered-target behavior
   as an incidental part of this extension.
4. If later selected, refine the scope and acceptance criteria before coding,
   including repeated declarations, forward/backward selection, boundaries,
   diagnostics and unchanged existing named/numbered programs. Keep experiments
   under `docs/tasks/C009/`; no artifact directory is needed while unstarted.

## Disposition

Listed only in the authoritative root TODO. No syntax is added to the language
specification or advertised as supported in the compatibility matrix or package.
